Detailed Description

The working buffer is held in one of two columns; a stage reads column src_sel and leaves the result in column dst_sel, laid out as 

 !!   [ words that stay (nkw) | from src (nrw) | from src2 (nr2w) ]
 !!

A stage that sends nothing keeps every word it holds, so it needs no copy and receives straight into the column it already occupies (inplace).
