subroutine schwarz::schwarz_compute ( class(schwarz_t), intent(inout) this,
real(kind=rp), dimension(this%dof%size()), intent(inout) e,
real(kind=rp), dimension(this%dof%size()), intent(inout) r,
type(c_ptr), intent(in), optional deps )
private
Parameters
ePreconditioned output.
rInput residual.
depsOptional device event the Schwarz work on the aux queue waits on before reading r. When absent, an event is recorded on the global queue at entry, which orders the Schwarz behind everything queued on the global queue so far. A caller that runs the Schwarz concurrently with other work on the global queue should record the event itself, before that work is queued, and pass it here; otherwise the Schwarz is ordered behind the concurrent work as well.
