hdf5_file::hdf5_layout_t Type Reference

Reusable distribution of a rank-ordered host array over NEKO_COMM. Counts are vector elements or matrix columns, not total matrix elements. Matrices distribute their second dimension; all ranks have the same number of rows and write every row of their local columns. Initialise collectively once, then reuse while every rank's local size and NEKO_COMM remain unchanged. Reinitialise after redistribution. More...

Parameters
local_countScalar integer: local number of vector elements or matrix columns. For a matrix use matget_ncols(), not matsize(). Pass only this rank's count, not an array of counts or dimensions.
Note
All ranks in NEKO_COMM must call this routine. A supplied layout removes size collectives from subsequent writes; callers must initialise it again on all ranks if any local count or the communicator changes.
