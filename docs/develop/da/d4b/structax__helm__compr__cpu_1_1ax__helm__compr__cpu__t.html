Detailed Description

Elements with the same geometric factors share one copy of them, coefG11_compr etc., and element e reads the copy coefcompression_inds(e). On a mesh of repeated element shapes this takes most of the six factors, 48 of the 80 bytes per point in double precision, out of the memory traffic of the product. Without compressed factors, see coef_t::enable_geo_compression, the product is the one of ax_helm_cpu_t.
