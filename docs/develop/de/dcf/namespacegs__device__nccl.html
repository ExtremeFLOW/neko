 Allocate the fused vector send and receive slabs in device memory, sized for GS_VEC_NC components. Deferred to the first fused exchange, see gs_comm_t. The NCCL communicator is built once at startup and the peer lists and dof maps come from init, so this stays rank local.

logical, parameter, public gs_device_nccl_avail = .false.
 Whether NCCL (or its ROCm equivalent RCCL) was built into this Neko (–with-nccl / –with-rccl). Lets callers (e.g. the gs comm. autotuner) skip the backend rather than aborting in init on builds without it.
