Detailed Description

Stores one scalar_bc_projector_t per global component and applies vector boundary conditions independently to x, y and z. This is suitable only for fully component-wise constraints. Like the underlying scalar projectors, this does not perform any real global resolution, we just feed it the Dirichlet dofs component-wise. Therefore, finalize is no-op.
