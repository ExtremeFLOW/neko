type  reichardt::reichardt_t
 Wall model based on Reichardt's law of the wall, \( u^+ = \frac{1}{\kappa} \ln(1 + \kappa y^+) + C \left[1 - e^{-y^+/B_1} - \frac{y^+}{B_1} e^{-y^+/B_2} \right] \), with the original constants \( C = 7.8 \), \( B_1 = 11 \) and \( B_2 = 3 \) as defaults.
