subroutine adv_oifs::adv_oifs_restart ( class(adv_oifs_t), intent(inout) this)
private

convr_GL, convs_GL and convt_GL are not stored in the checkpoint. They are recomputed from the restored lagged velocities, first lf(2) and then lf(1). The next call to compute or compute_scalar adds the current velocity, as in a run without restart.
