Detailed Description

A registry for storing and requesting temporary objects.

This type is used to store temporary objects that can be requested and relinquished by the user. It is designed to be used in situations where a function is called frequently and temporary objects are needed, but creating and destroying them on each call would be inefficient. The scratch registry allows for the reuse of these objects, improving performance.

The registry is OpenMP thread-safe, allowing for concurrent access in parallel regions in the sense that each thread can request and relinquish objects independently.
