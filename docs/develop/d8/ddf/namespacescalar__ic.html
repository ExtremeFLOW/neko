subroutine scalar_ic::set_scalar_ic_expression ( type(field_t), intent(inout) s,
character(len=*), intent(in) expr )
private

Set the scalar initial condition from a mathematical expression, evaluated in every GLL point of the mesh with x, y and z bound to the coordinates of the point. Constants declared under case.constants in the case file can be referred to by name, see the expression module for the full syntax.

Parameters
sScalar field.
exprThe expression prescribing the initial value.
