pde_filter Module Reference

A PDE based filter.

Data Types

type  pde_filter_t
 A PDE based filter mapping \(\rho \mapsto \tilde{\rho}\), see Lazarov & O. Sigmund 2010, by solving an equation of the form \( -r^2 \nabla^2 \tilde{\rho} + \tilde{\rho} = \rho \). More...
