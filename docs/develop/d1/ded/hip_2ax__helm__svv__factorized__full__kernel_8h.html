Fused device kernel for the factorized SVV stress (full) operator

Evaluates, in a single pass over each element, the standard stress formulation built from D and h1, plus the factorized SVV stress built from the complementary derivatives B = (Br, Bs, Bt) and h1_svv. This mirrors ax_helm_svv_factorized_full_lx in the CPU backend: both contributions share the k-plane sweep, the geometric factors are loaded once, and (au, av, aw) are stored once (no read-modify-write of the output).

The kernel is kept separate from the autotuned ax_helm kernels on purpose, so that those keep their register footprint untouched. Within each k-plane the standard and SVV fluxes are formed one after the other, so only the three t-direction fluxes of each need to be live at the same time.

PAD selects a shared memory pitch of LX+1, removing bank conflicts when LX is a power of two. Map reference derivatives of (u, v, w) to the reference-space fluxes of the symmetric stress tensor, scaled by dj. The r- and s-fluxes are written to shared memory, the t-fluxes are returned in registers.
