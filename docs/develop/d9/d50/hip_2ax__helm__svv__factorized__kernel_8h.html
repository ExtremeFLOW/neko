__global__ void __launch_bounds__ ( LX * LX)

Fused device kernel for the factorized SVV Helmholtz operator

Evaluates, in a single pass over each element, w = D^T (h1 G) D u + B^T (h1_svv G) B u, with B = (Br, Bs, Bt) the complementary (filtered) derivative matrices. This mirrors ax_helm_svv_factorized_lx in the CPU backend: both contractions share the k-plane sweep, the geometric factors are loaded once, and w is stored once (no read-modify-write of the output).

The kernel is kept separate from the autotuned ax_helm kernels on purpose, so that those keep their register footprint untouched.

PAD selects a shared memory pitch of LX+1, removing bank conflicts when LX is a power of two.
