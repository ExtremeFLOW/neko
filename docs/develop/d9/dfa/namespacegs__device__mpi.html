subroutine gs_device_mpi::gs_device_mpi_nbrecv ( class(gs_device_mpi_t), intent(inout) this,
integer, intent(in) tag )
private
Note
With per-peer unpacking (strategy bit 2) the previous op unpacks each slot of the receive buffer on its own stream, and nothing on the host waits for that afterwards: the caller need not sync after the op. Each slot's unpack event is therefore waited on before the slot is posted again, so that MPI cannot overwrite data that is still to be read. The wait is normally on an event that has already completed.
